# チャットで選択肢を出す

オーナーのアプリ（Plasmod）のチャットは、返事の中の ```choices のブロックを**押せるボタン**にする。押されると、そのラベルがオーナーの発言としてそのまま届く。

## 書き方

質問の文を先に書き、その後にブロックを置く。1行に1つ、`- ラベル — 説明`（説明は無くてよい。区切りは「 — 」か「 -- 」）。

````
どちらで進めますか？

```choices
- A 案で進める — 早いが、あとで手直しが要る
- B 案で進める — 1日かかるが、作り直しが要らない
- いったん止める
```
````

複数選んでよいときは ```choices multi にする。届く発言は、選んだラベルを「、」でつないだもの（例: `メール、カレンダー`）。

## 決まり

- 選択肢は2〜5個（8個まで表示）。ラベルは短く、押した発言だけで意味が通るようにする（「はい」より「A 案で進める」）
- おすすめがあれば先頭に置き、説明に「（おすすめ）」と書く
- 「その他」は書かない。オーナーは入力欄から自由に答えられる
- 1つの返事にブロックは1つ。返事のいちばん最後に置く
- 押せるのは、いちばん新しい返事の選択肢だけ。前の返事のものは、選ばれた印が付いて押せなくなる
- アプリ以外では、ただのコードの囲みとして見える。読めば分かるように書く
